# Smart Operator Assistant for CAT Machinery

**PREDICT → EXPLAIN → SIMULATE → LEARN** — a prototype operator companion for excavators and wheel loaders: predictive safety with explanations, an Operator Digital Twin with personalised anomaly detection, task-time prediction, 3D safety simulation, safety replay, counterfactual what-if analysis and adaptive microlearning.

> **Prototype.** Built on a *synthetic* dataset generated by this project. It is not real CAT telemetry, does not use official CAT thresholds, and has not been validated on real machines. Risk scores are project-defined metrics.

## Quick start (data + models)

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
bash scripts/train_all.sh                               # data → validation → EDA → 3 models → report → 24 tests (~3 min)
```

Trained models are committed in `models/`, so this step is only needed to reproduce them. On Windows without bash, run the commands listed in `scripts/train_all.sh` one by one.

## Models (synthetic test data, unseen operators)

| Model | Selected | Headline |
|---|---|---|
| Safety risk (4 levels + 0–100 index) | logistic regression + hazard interaction terms | HIGH∪CRITICAL recall 0.896 · ROC-AUC 0.950 · 0 CRITICAL→LOW |
| Personal anomaly (Digital Twin) | Isolation Forest on personal z-scores | PR-AUC 0.807 vs 0.625 without personalisation |
| Task time (remaining / total) | gradient boosting, log target | MAE 11.1 / 20.3 min vs planner 28.4 / 56.4 · 80 % range coverage 79 % / 80 % |

Methodology, leakage controls and limitations: `docs/ml_methodology.md`. Full tables: `reports/model_report.md`.
